## 实现计划（按 P0–P6，一个 Priority 验收后再进入下一个）

### P0 — Version Cleanup + Reuse Gate（无需硬件，本轮后即可实施）
1. CHANGELOG：`[0.0.1]` 修正、新增 `[0.0.2] - Unreleased`
2. README 能力状态表格化（Implemented / Simulator Validated / Real Hardware Validated / Experimental / Not Implemented）
3. AI_DEV_GUIDE.md 增加 Reuse Gate 章节（§31 规则固化）
4. fw.psm1 + instruments.py 注册 5 个新 Error Class
5. 验收：文档一致性检查 + `doctor` 全绿

### P1 — Build Backend Dispatch
1. build.ps1 重构：backend switch（cmake/make/platformio/keil/iar/zephyr/esp-idf）
2. Detection precedence：-Backend > 项目配置 > 强标记（west.yml/idf 等）> 通用检测
3. Artifact Manifest（firmware-artifacts/v1，ELF/AXF/OUT/HEX/BIN 归一）
4. CI：cmake+make 真跑；keil/iar/zephyr/esp-idf/platformio fake executable 命令构造测试
5. 验收：backend 命令测试全绿（新增 tests/backend/ 或 CI 步骤）

### P2 — Agentic HIL 接线 + 外置安全 + Qoder MCP
1. flash.ps1 移除猜测 CLI（agentic-hil 分支改提示/仅 simulator+vendor）；`tools/lib/` 不新增 MCP client
2. limits 外置：%APPDATA%\FirmwareLoop\benches\<id>\limits.yaml + FIRMWARELOOP_BENCH_CONFIG；repo 只留 limits.example.yaml；Fail Closed + Tamper Test（新增 tests/safety/）
3. .mcp.example.json 提交，.mcp.json gitignore；tools/check-qoder-mcp.ps1（detect/verify/register/verify）
4. 验收：Tamper Test 通过；check-qoder-mcp 在无 Qoder 时给出明确错误

### P3 — Real DUT（需硬件）
1. adopt-hardware 载入探针；test-plans/real-smoke.yaml（逻辑设备名）按 test-schema v3/v4 编写
2. acceptance-scenario.ps1 `-Mode real`：build → test-reactor(flash/reset/UART expect) → logic → instrument → pytest(agentic_hil 插件) → report
3. conftest：serial 直连降级为 `direct-serial`（默认 disabled + HARDWARE_GATE_BYPASSED）
4. 验收：真机 probe/flash/reset/UART 证据入 runs/

### P4 — Real VISA
1. tools/lib/instruments.py 抽取（open/identify/query/normalize/timeout/close/error mapping）
2. instrument_cli.py + pytest fixtures 共用；capture-waveform 移除假数据（visa → CAPABILITY_NOT_SUPPORTED 除非 profile 支持）
3. Profile（依据官方 Programming Manual，如 rigol-ds1000z）
4. 验收：真机 IDN + 一项真实测量（frequency/Vpp/voltage/current）入 evidence

### P5 — Saleae / sigrok（需硬件）
1. Agent Lane：Saleae MCP（Qoder 内）
2. Headless Lane：Saleae Automation API；fallback sigrok-cli
3. 统一证据 logic-capture-result/v1（real_hardware: true）
4. 验收：SPI 或 I2C 或 UART 真机 decode 证据

### P6 — Real Acceptance + Evidence + Release
1. Evidence Layout 补全（environment.json / dependencies.json / build.json / hardware.json / logic/ / instruments/ / final-report.md）
2. 真实闭环验收（≤3 次迭代）；README Validation 状态准确
3. `git tag v0.0.2`（满足 §29 全部 DoD 后）

## 阻塞项（影响 P3–P5 验收）

- 无真实 DUT / 调试器 / 仪器 / 逻辑分析仪（本机只有蓝牙串口 COM5）

- 无 Qoder 本机配置（P2 的 check-qoder-mcp 只能做 detect 路径验证）
